## Overview

Canvas & Cradle gives small businesses a ready-made web foundation built from HTML, CSS, and JavaScript. Its focused landing page is structured for introducing a company, service, or product, with dedicated areas for pricing, common questions, and collecting leads.

The project is intended for organizations that need an uncomplicated and customizable online presence rather than a substantial application framework. Its responsive design, dark canvas aesthetic, cursor spotlight interaction, reduced-motion support, and touch-device handling make it suitable for current desktop and mobile browsers.

## Project Configuration

There is no separate runtime configuration layer. Make changes directly within the project files:

- **HTML:** Change page copy, navigation, prices, FAQ content, forms, and legal information.
- **CSS:** Customize the color palette, type, spacing, responsive rules, and dark canvas styling.
- **JavaScript:** Modify behaviors including the cursor spotlight and form interactions.
- **Static hosting:** Set the repository or hosting service to serve the project directory as a static website.

When working with more than one HTML page, preserve the links between pages if you rename files or change the deployment location.

## Frequently Asked Questions

### What kind of project is Canvas & Cradle suited to?

Canvas & Cradle is aimed at small businesses, independent teams, and creators looking for a responsive site or landing page starting point.

### What is the quickest way to view it?

Clone or download the project, then open the main HTML file in a current web browser.

### Is GitHub Pages supported?

Yes. Since the project consists of self-contained web pages, it can be published with GitHub Pages or another static hosting provider.

### Which files contain the business information?

The relevant HTML files contain the landing page wording, navigation, pricing, FAQs, forms, and legal-page content. Edit those files to replace the sample material.

### What is needed to activate the lead form?

The template includes a lead capture integration point. Before publishing, configure the form for the service or endpoint you have chosen.

### Does the visual interaction support touch screens?

Yes. Touch-device support is included, and the motion behavior also respects reduced-motion preferences.

### What can I investigate if the page renders incorrectly?

First verify that the CSS and JavaScript files are still located where the HTML expects them, then refresh the page in a current browser. For deployments under a subdirectory, also check that all page and asset paths point to the correct locations.

### Where can I find newer versions?

Review the repository for later releases or updates. Before deploying an update, compare those changes with your customized project files.
